rNitro Linux v0.1 Beta Pre-release
==================================

Extract this archive and run:

  bash install-rNitro-linux.sh

Requirements:
  - Python 3.10+
  - python3-gi, GTK 4, libadwaita (gir1.2-gtk-4.0, gir1.2-adw-1)
  - Recommended: pip install psutil (installer does this automatically)
  - Optional: lm-sensors, nvidia-smi, Ayatana AppIndicator for tray

Features: Monitor, Advisor, Chat, App Cleaner — mirrors macOS beta tabs.
Config stored at ~/.config/rnitro/settings.json
Apple-only metrics (SMC, Low Power Mode) show as N/A on Linux.
