About rNitro CLI

rNitro CLI (v0.2-cli) is a terminal dashboard in the spirit of btop — for when you want the same rNitro metrics over SSH or without a menu bar.

  • Live stats — CPU, memory, disk I/O, network, battery, and top processes
  • Where it runs — macOS and Linux, Python 3, no GUI required
  • Keys — q quit · r refresh · rnitro --once for one-shot JSON
  • Install — tarball + install-cli.sh, or the one-line curl install below

How to install

1

Download or curl-install

Use the CLI tarball above, or paste this one-liner in Terminal:

curl -fsSL https://getrnitro.netlify.app/rNitro-CLI.tar.gz -o /tmp/rnitro-cli.tar.gz && mkdir -p /tmp/rnitro-cli && tar xzf /tmp/rnitro-cli.tar.gz -C /tmp/rnitro-cli && bash /tmp/rnitro-cli/install-cli.sh
2

Install to your PATH

From the extracted folder: bash install-cli.sh — links rnitro to ~/bin (or sudo ./install-cli.sh --system for /usr/local/bin).

3

Run rNitro in the terminal

Type rnitro for the live dashboard. Works over SSH. Optional: pip3 install psutil for smoother stats.
