How to install
1

Download the PKG, DMG, or App ZIP

Choose Stable (green, OpenAI + OpenRouter) or Beta (orange, all AI APIs). Agree to the Terms & Conditions, then pick a format:

  • PKG — double-click; installs to Applications (admin password).
  • DMG — open the disk image and drag rNitro.app to Applications.
  • Apps ZIP — one file with both Stable and Beta .app bundles.

⚠ macOS security prompt: When you open the PKG, macOS may say it can't verify the file. That's normal for indie apps. Don't click Move to Trash. Click Done, then go to System Settings → Privacy & Security and press Open at the bottom.

2

Or install from Terminal with curl

No browser download needed — paste a one-liner in Terminal. It fetches the .sh installer (readable source), saves it to /tmp, then runs it. Stable:

Paste in Terminal (Apple Silicon Mac, Xcode CLT required). The script is saved to disk first — curl | bash is blocked on purpose.

curl -fsSL https://getrnitro.netlify.app/rNitro-v1.1.0-Final-Reloaded.sh -o /tmp/rnitro-install.sh && bash /tmp/rnitro-install.sh

Beta (v1.2.1):

curl -fsSL https://getrnitro.netlify.app/rNitro-v1.2.1.sh -o /tmp/rnitro-install.sh && bash /tmp/rnitro-install.sh

Installs to ~/Applications/rNitro.app in ~30 seconds. Self-verifies its SHA-256 checksum before running.

3

First launch

If macOS blocks the app, right-click rNitro.app → Open once. No telemetry, no account — runs fully local.

1

Install dependencies

Ubuntu/Debian: sudo apt install python3-gi python3-venv gir1.2-adw-1 gir1.2-gtk-4.0 lm-sensors. Fedora: sudo dnf install python3-gobject gtk4 libadwaita.

2

Download and install

Switch to the Linux tab, download rNitro-v0.1-Linux-Beta-Pre-release-x64.tar.gz or install-rNitro-linux.sh, extract if needed, and run bash install-rNitro-linux.sh. Also on GitHub Releases. Installs to ~/.local/share/rnitro with a desktop entry.

3

Use rNitro

Launch from your app menu or the system tray. Monitor, Advisor, Chat, and Cleaner tabs mirror the macOS beta feature set (platform-specific metrics where applicable).

Windows is no longer actively supported. The last build (v4.2.4-Windows-Final-x86) remains available for download below.

1

Download the EXE (easiest)

Switch to the Windows tab and download rNitro-v4.2.4-Windows-Final-x86.exe. If Windows asks for a runtime, install the .NET 8 Desktop Runtime (x64) first, then run the EXE again.

2

Or compile from source

Download rNitro-v4.2.4-Windows-Final-x86.ps1, open PowerShell, and run:

powershell -ExecutionPolicy Bypass -File $env:USERPROFILE\Downloads\rNitro-v4.2.4-Windows-Final-x86.ps1

Compiles with csc.exe (built into Windows 10/11) and installs to %LOCALAPPDATA%\rNitro — ~15 seconds. No SDK required.

3

Use rNitro

rNitro runs in the system tray (bottom-right). Click the icon for live CPU%, temperature, RAM, BTC price, and 60-second history graphs. Right-click the tray icon to quit.

For new installs we recommend macOS or the Linux tab instead.

1

Download or curl-install

Switch to the CLI tab and download rNitro-CLI.tar.gz, or paste this one-liner in Terminal:

curl -fsSL https://getrnitro.netlify.app/rNitro-CLI.tar.gz -o /tmp/rnitro-cli.tar.gz && mkdir -p /tmp/rnitro-cli && tar xzf /tmp/rnitro-cli.tar.gz -C /tmp/rnitro-cli && bash /tmp/rnitro-cli/install-cli.sh
2

Install to your PATH

From the extracted folder: bash install-cli.sh — links rnitro to ~/bin (or use sudo ./install-cli.sh --system for /usr/local/bin).

3

Run rNitro in the terminal

Type rnitro for the live dashboard (like btop). Works over SSH. Same rNitro metrics — no menubar app required.
