## Full description (paste into AlternativeTo)

**rNitro** is a free, open-source menu bar system monitor for Apple Silicon Macs (with Linux and Windows companions).

It lives in your menu bar and shows live **CPU**, **temperature**, **battery**, **GPU**, **RAM**, **network**, and power — without accounts, subscriptions, or telemetry.

### Why people switch from iStat Menus / Stats / etc.
- **Actually free** — no paywall for core monitoring  
- **No account / no cloud lock-in** — install and go  
- **Privacy-first** — no telemetry by design  
- **Modern macOS UI** — SwiftUI popover + main window  
- **Optional AI** (bring your own keys) — Stable: OpenAI + OpenRouter; Beta: full provider list  
- **Lab tools** (Beta+) — thermal “weather,” why-hot detective, Whisper menubar, compile-farm detection, power receipt, time-scrub  
- **Experimental channel** — playground features for power users  
- **App ZIP install** — no admin password required for the recommended path

### Install (macOS App ZIP)
1. Download App ZIP from the site or GitHub  
2. Unzip → drag **rNitro.app** to Applications  
3. Right-click → Open the first time if Gatekeeper asks  

Or compile from source:
```bash
curl -fsSL https://getrnitro.netlify.app/rNitro-v1.1.0-Final-Reloaded.sh -o /tmp/rnitro-install.sh && bash /tmp/rnitro-install.sh
```
