## Description (Product Hunt body)

**rNitro** is a free menu bar system monitor for Apple Silicon Macs.

It shows live **CPU**, **temperature**, **battery**, **GPU**, **RAM**, and **network** without accounts, subscriptions, or telemetry.

### Built for people who actually want a menubar monitor
- One click in the menu bar — not another full-window dashboard  
- **App ZIP** install (no admin password)  
- **Stable** for daily use, **Beta** for Lab + every AI provider, **Experimental** for toys  
- System Advisor with temp/CPU/RAM/GPU/battery thresholds (no API key)  
- Optional AI chat with *your* keys (OpenAI, OpenRouter on Stable; more on Beta)  
- Open source — inspect the installer and app source on GitHub  

### Channels
- **Stable v1.2.0 Final** — clean daily driver  
- **Beta v1.2.7** — Slim Lab (weather, detective, Whisper, compile-farm, power receipt) + full AI list  
- **Experimental v1.2.7** — everything in Beta plus duel, cloak, SOC budget, widgets, more  

### Platforms
macOS (primary) · Linux pre-release · Windows last builds available  

### Privacy
No accounts. No telemetry. Keys you add stay on your machine.
