## Short (≈120 words)

**rNitro** is a free, open-source macOS menu bar system monitor (CPU, temps, battery, GPU, RAM, network) — no account, no telemetry.

Three channels:

- **Stable** — daily driver; OpenAI + OpenRouter for optional AI chat  
- **Beta** — Lab tools + every AI provider  
- **Experimental** — playground toys (unstable on purpose)

In-app updates, Terms on every download (Agree / Disagree), and optional Fathom for “what drained my battery.”

**Site:** https://chopstickshq.com/rnitro/  
**Code / releases:** https://github.com/ilikemacos/rNitro  

Not affiliated with iStat. Feedback welcome.

## Medium (Show HN / blog)

**Title:** rNitro — free open-source Mac menu bar monitor (Stable / Beta / Experimental)

rNitro is a native Swift menu bar monitor for Apple Silicon (and Intel best-effort). Live CPU, package watts where available, temperatures, battery, memory, network — fully local.

**Why three channels?**

| | Stable | Beta | Experimental |
|---|--------|------|----------------|
| Use | Daily | Power users | Playground |
| AI | OpenAI + OpenRouter | All providers | Same as Beta + toys |
| Risk | Low | Medium | High |

Downloads gate on Terms (Agree continues; Disagree returns home). Optional “remember for this session.” Experimental gets auto-update on its own channel.

Pair with **Fathom** (https://chopstickshq.com/fathom/) for local battery-drain attribution — rNitro links from Monitor → Battery.
