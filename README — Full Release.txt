rNitro Full Release Bundle
==========================

Double-click rNitro-Full-Release.pkg to install everything to /Users/Shared/rNitro-Full-Release
(admin password required; Finder opens the folder when done).

CONTENTS
--------
  website/index.html            — download website (open locally in browser)
  index.html + version.json     — same site files at zip root
  rNitro-v7.1.1-Final-arm64.pkg               — Stable app installer (no AI chat)
  rNitro-v8.2.1-Beta-arm64.pkg                 — Beta app installer (with AI chat)
  rNitro-v7.1.1-Final-arm64.sh / rNitro-v8.2.1-Beta-arm64.sh — source compile installers
  rNitro-v4.2.1-Windows-Final-x86.exe / rNitro-v4.2.1-Windows-Final-x86.ps1   — Windows builds
  terms-and-conditions.txt
  build scripts + favicons

QUICK START (macOS)
-------------------
1. Agree to Terms on the website before download
2. Double-click rNitro-v7.1.1-Final-arm64.pkg or rNitro-v8.2.1-Beta-arm64.pkg to install rNitro.app to Applications
3. Or run: bash rNitro-v7.1.1-Final-arm64.sh (stable) / bash rNitro-v8.2.1-Beta-arm64.sh (beta) to compile from source
